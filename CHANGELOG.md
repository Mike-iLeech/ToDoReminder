# История изменений — ToDo Reminder

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/) и
[Semantic Versioning](https://semver.org/lang/ru/).
Актуальная версия: **v2.6.3.2** (2026-08-16).

История ведётся с полного переписывания приложения (v2.0 «Full Rebuild»).
Всё, что было до этого — старая версия 1.x, чей код в текущей кодовой базе не сохранился.

---

## [2.6.3.2] — 2026-08-16

### Исправлено
- **Цвет срочных дел при переключении темы:** цвет текста срочных дел в полноэкранном
  напоминании теперь также подставляется под новую тему (акцентный красный той же темы)
  наравне с обычным текстом. Раньше цвет оставался неизменным после переключения темы.

## [2.6.3.1] — 2026-08-16

### Добавлено
- **Ограничение общего числа колонок:** сумма колонок To Do + Started (+ Done, если включён)
  не может превышать 12. При превышении значения автоматически ограничиваются.
- **Импорт/экспорт JSON с метками срочности:** при экспорте в JSON сохраняются поля `urgent` и `regular`;
  при импорте из JSON эти флаги восстанавливаются на задачах (TXT/CSV — без флагов).

### Исправлено
- **Цвет текста при переключении темы:** теперь при смене темы цвет текста напоминания
  всегда подставляется контрастный к новому фону, даже если пользователь ранее менял цвета вручную.

## [2.6.3.0] — 2026-08-16

### Добавлено
- **Отдельная настройка числа колонок для Done:** при включённом выводе выполненных дел
  в полноэкранном напоминании можно настроить число колонок Done (от 1 до 8) независимо
  от To Do и Started. Настройка видна только когда «Выводить выполненные дела» включено.

## [2.6.2.3] — 2026-08-16

### Добавлено
- **Настраиваемое число колонок в полноэкранном напоминании:** отдельно для To Do и Started (от 1 до 8). По умолчанию — 2 колонки на каждый статус. Настройки доступны в окне настроек.

## [2.6.2.2] — 2026-08-16

### Исправлено
- **Обрезка букв в полноэкранном напоминании:** адаптивный размер шрифта теперь
  проверяет не только высоту колонки, но и **ширину самого длинного слова**.
  Если слово не помещается по горизонтали — размер уменьшается бинарным поиском.

## [2.6.2.1] — 2026-08-16

### Добавлено
- **4-колоночный полноэкранный режим:** задачи распределяются по колонкам
  ToDo-1, ToDo-2, Started-1, Started-2 (round-robin). При включённом показе Done —
  добавляются колонки Done-1 и Done-2.
- **Адаптивный размер шрифта:** бинарный поиск от базового размера до минимального
  (`fullscreen_min_font_size`, по умолчанию 14 px) — текст всегда помещается в колонку.
- **Срочные задачи (⚡):** увеличенный на `urgent_fullscreen_size_delta` (5 px) шрифт,
  значок ⚡ перед названием, закрепление вверху колонки.

### Изменено
- Полноэкранное напоминание полностью переписано: новая логика распределения,
  отрисовка и адаптации размера.
- Раздел 7 справки обновлён под новую 4-колоночную схему.

## [2.6.1.1] — 2026-08-15

### Добавлено
- **Автоудаление Done-задач:** при запуске приложения все выполненные (Done) задачи
  удаляются автоматически. Ежедневный сброс регулярных задач также очищает Done.

## [2.6.1] — 2026-08-15

### Добавлено
- **Срочные задачи:** правый клик по карточке → «Срочное» (отмечается значком ⚡).
  Срочные дела отображаются с увеличенным шрифтом и закреплены вверху колонки
  в полноэкранном напоминании.

## [2.6.0] — 2026-08-15

### Добавлено
- **Срочные задачи (базовая поддержка):** поле `urgent` в модели задачи,
  контекстное меню «Срочное», блокировка перетаскивания срочных задач,
  сортировка срочных наверх.
- Цвет и размер срочных задач в полноэкранном режиме настраиваются
  (`urgent_fullscreen_size_delta`).

## [2.5.0] — 2026-08-13

### Добавлено
- Окно **«Справка»** (кнопка «?») — полноценный справочник по приложению
  (ввод, кнопки, статусы, регулярные задачи, таймер, настройки, трей, лимиты).
- Справка рендерится в **текущей теме**: тёмный фон в тёмной теме, светлый — в светлой.

### Исправлено
- Текст справки больше не лежит на «подложке» (карточках-блоках): заголовки и текст
  идут прямо по фону окна, у `QTextBrowser` убраны рамка и внутренние отступы.
- Опечатка в тексте справки («отдела» → «от дела»).

### Прочее
- Подготовлен релиз для публикации на GitHub (README, CHANGELOG, LICENSE, .gitignore).
- Версия приложения вынесена в `version.py` и показывается в окне «О программе».

## [2.4.0] — переименование и модальность

### Изменено
- **Переименование** стало удобнее: **Enter** или **клик мышкой вне поля** — сохранить новое имя,
  **Esc** — отменить изменения.
- Окно **настроек** стало модальным: пока оно открыто, главное окно недоступно
  (нельзя случайно потерять несохранённые значения).

## [2.3.0] — регулярные задачи

### Добавлено
- Правый клик по карточке → пункт **«Регулярное»** (отмечается галочкой).
  Такие дела помечаются значком **⟳**.
- С наступлением **нового календарного дня** статус регулярного дела автоматически
  сбрасывается в **To Do** и оно поднимается в **самый верх** списка.
- Сброс работает даже если приложение было полностью закрыто (проверка при запуске
  + таймер раз в час).

## [2.2.1] — кнопка очистки

### Добавлено
- Кнопка **«Очистить список»** (красный крестик ✕) — удаляет весь список
  **только после подтверждения** (по умолчанию ответ «Нет»).

## [2.2.0] — тёмная тема

### Добавлено
- **Тёмная тема для окна настроек**: выпадающие списки, спинбоксы, чекбоксы.
- **Тёмные заголовки (шапки) всех окон** через `DwmSetWindowAttribute`
  (DWMWA_USE_IMMERSIVE_DARK_MODE) с принудительным обновлением рамки при смене темы.

## [2.1.1] — цвета статусов и фикс

### Добавлено
- Настройка **цветов статусов** To Do / Started / Done (палитра в окне настроек).
  Цвета применяются к карточкам в списке и к маркерам в полноэкранном напоминании.

### Исправлено
- Кнопка статуса больше не «пропадает» при переименовании: поле редактирования
  теперь накладывается поверх названия, а не скрывает кнопку.

## [2.1.0] — обратный цикл статусов

### Добавлено
- **Правый клик (ПКМ)** по кнопке статуса — цикл **назад**:
  Done → Started → To Do → Done.
- ЛКМ — цикл **вперёд**: To Do → Started → Done → To Do.

## [2.0.0] — Full Rebuild

Полное переписывание приложения (Python + PySide6). Основа всей текущей версии.

### Добавлено
- Главное окно **300×700** (фиксированный размер).
- Один вертикальный список задач (без разделения по статусам).
- Быстрое добавление: **Enter** или кнопка «✓»; новые дела — сверху списка.
- Статусы **To Do / Started / Done** одной кнопкой по кругу (ЛКМ); выполненные
  дела зачёркиваются.
- **Drag & drop** перестановка дел (без «призрака»).
- **Таймер** обратного отсчёта до напоминания + настройка интервала (− / + / поле «мин»).
- **Полноэкранное напоминание** — список по колонкам статусов, закрытие кликом
  или Enter/Space/Esc, режим «поверх всех окон», скрытие выполненных дел.
- **Системный трей**: закрытие сворачивает в трей, ЛКМ возвращает окно, ПКМ — меню.
- **Тёмная и светлая темы**.
- **Импорт / экспорт** JSON / TXT / CSV (с вопросом «Заменить/Добавить»).
- Лимит **100 дел**.
- **Портативность**: данные в папке `data` рядом с приложением.
- Окно «О программе» с благодарностью 💙.
